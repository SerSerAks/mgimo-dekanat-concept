# Цифровой деканат · концепт для МГИМО

Рабочий прототип личного кабинета студента — «цифрового деканата будущего» — для конкурса.
**Это концепт, а не официальный сервис МГИМО.** Все студенты, оценки, заявки и преподаватели вымышлены.

**Прототип:** https://lkstudenta.ru
**Тестовые аккаунты:** логины — на странице входа («Тестовые аккаунты для жюри»), пароли — в комментарии к конкурсной работе.

## Что внутри

| Роль | Что может |
|---|---|
| Студент: бакалавр, магистр, аспирант | «Сегодня» с расписанием и изменениями, расписание по дням, успеваемость (текущие баллы, экзамены, зачёты, учебный процесс, практика), заявки и справки со статусом, уведомления, антиплагиат, мероприятия МГИМО |
| Деканат | Очередь заявок и смена статусов, объявления факультету / курсу / группе, сроки практики по направлениям, список студентов |
| Научный руководитель | Свои студенты и их работы |
| Выпускающая кафедра | Выпускники кафедры и их ВКР |

Главная идея — сквозной путь студента: один аккаунт на бакалавриат, магистратуру и аспирантуру, история не теряется. Подробно — [docs/SPEC.md](docs/SPEC.md).

## Реальные открытые данные МГИМО

- Расписание трёх реальных групп — разовый импорт из открытого API РУЗ, **без ФИО и e-mail преподавателей** ([scripts/import-ruz.ts](scripts/import-ruz.ts)).
- Факультеты, направления и места приёма 2026 — из открытых PDF приёма, суммы сверены с итогами ([docs/content/programs.csv](docs/content/programs.csv)).
- Анонсы мероприятий — с mgimo.ru, ссылками на источник.

Кабинет в работе к системам МГИМО не обращается — только к собственной базе.

## Безопасность — коротко

- Пароли хранятся только в виде хеша argon2id; вход ограничен 5 попытками за 5 минут.
- Сессия — случайный токен в httpOnly-cookie, в базе хранится только его хеш.
- Все правила доступа — в одном файле [src/lib/access.ts](src/lib/access.ts). Любой объект ищется вместе с условием «что этому пользователю видно»: чужая заявка по прямой ссылке даёт 404.
- Деканат видит только свой факультет, научный руководитель — только своих студентов, кафедра — только своих выпускников.
- Ключи и пароли от сервисов — только в переменных окружения на сервере, не в коде и не в браузере.
- Автопроверка: `npm run test:access` — 11 сценариев «кто что видит».

## Стек

Next.js 15 (App Router, TypeScript), Tailwind CSS + shadcn/ui, PostgreSQL 16 + Prisma, Docker, Caddy (HTTPS). Сервер в Москве. Шрифт Montserrat (OFL), иконки Lucide (ISC).

## Запуск локально

```bash
cp .env.example .env    # заполнить пароль базы и APP_SECRET
docker compose up -d    # PostgreSQL на порту 5433
npm install
npx prisma migrate dev
npm run db:seed         # тестовые данные; пароли → .demo-accounts.local.md
npm run dev             # http://localhost:3000
```

Деплой — [docs/DEPLOY.md](docs/DEPLOY.md).
